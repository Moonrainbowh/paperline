# Paperline 本地科研工作台

在仓库根目录运行（Python 3.10+，仅标准库）：

```powershell
python -X utf8 webui/server.py
```

打开 http://127.0.0.1:8765 。端口被占用时加 `--port 8766`。

## 本次集成

- 流水线总览：P1–P5 的已有能力、依据和人工确认门。
- 能力与文档：实时扫描四个 Skill，按模块筛选和文件名搜索，查看原文。
- 质量校验：7 个固定 Python 命令，后台执行，显示退出码、时间和输出；同一时间运行一项。结果随服务重启清空。
- 运行记录：读取 `runs/*/records.json`，统计 `runs/**/pipeline-state.json`。
- 待建设环节：明确展示模型执行、项目管理、人工确认、绘图、工具连接、真实验收与发布缺口。

阶段与缺口说明是本次源码审查的策展内容，保存在 `static/app.js`，功能增加后需要同步更新。文件清单、记录和校验结果实时读取。

这是本地集成工作台。当前不执行模型写作、选刊、翻译或投稿，不创建或修改论文阶段状态。既有 Skill 描述为宿主 Agent 的工作指引；校验器不是这些工作的自动执行引擎。真实论文的 S7 锁定仍须作者对确切版本确认。

服务只监听回环地址，文档阅读使用文件清单，运行使用固定命令清单。
