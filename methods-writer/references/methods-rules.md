# 方法规则

方法小节应说明：研究对象、数据或材料、预处理、实验/模拟/模型步骤、参数和边界、对照与基线、评价指标、统计或误差处理、复现所需信息。

每个关键步骤都尽量写成“输入 → 操作 → 输出 → 目的/验证”。方法章节描述设计与执行，不把观察到的性能或机制提前写入方法。

## 章节与段落蓝图

按任务与范围 → 数据/材料/工况 → 总体路线 → 研究步骤 → 参数与实现 → 评价设计 → 复现边界组织适用内容。每个关键步骤写清：为什么需要、输入及单位、实际操作、影响结果的设定、输出如何进入下一步。

评价设计逐项回答研究问题、变量与控制、基线/对照、比较条件、指标定义及方向、不确定性和会削弱主张的结果。不要强迫无实验论文套用实验模板；图形能降低理解成本时再把文字路线交给图表 Skill。

## 本节检查

- 关键结果都有对应的方法、指标和比较设计。
- 会影响结果的预处理、排除、划分、参数、停止条件和统计处理可以核查。
- 比较使用的输入、预算、调参和评价条件透明；缺项明确标记。
- 计划执行、用户陈述和有产物支持的已执行流程分开，不将缺失记录补成事实。
