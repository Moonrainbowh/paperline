# 引言规则

引言不是逐篇罗列文献，而是围绕一个研究问题组织论证：

1. 说明研究对象和问题为什么重要；
2. 概括与当前问题直接相关的研究进展；
3. 指出已有工作在哪些条件、证据或方法上仍有缺口；
4. 明确本文要回答的问题、研究动作和贡献；
5. 说明贡献能够被哪些方法和结果检验。

不要把没有结果支撑的实现细节包装成创新，也不要把尚未决定的科学解释写成定论。

## 段落蓝图与版本

完整引言可按以下任务组织，段数随材料调整：

| 段落任务 | 论证顺序与证据要求 |
| --- | --- |
| 对象与价值 | 定义对象/场景 → 具体问题及后果 → 收束到本文问题 |
| 主流路径与限制 | 按研究路线概括进展 → 给出来源 → 指出在特定条件下的限制 |
| 最接近工作与缺口 | 公平比较已解决内容 → 未覆盖条件或能力 → 可验证缺口及其重要性 |
| 本文目标与路线 | 承接缺口 → 目标/假设 → 方法概览 → 研究范围 |
| 贡献与证据预告 | 研究动作 → 新增认识或能力 → 方法及结果位置 → 适用边界 |

相关工作按统一比较轴综合最相关路线；独立相关工作章节与引言不重复罗列。未检索或未读全文的范围不能支持“首次”“从未研究”等断言。

第 0 版只把主旨、缺口、路线和预期证据外化，待核项显式保留；它不能充当最终引言。回写最终版时依据真实方法和结果逐项保留、收窄或删除承诺。新贡献或科学解释存在实质选择时交给作者决定，不用早期设想替代已完成证据。

## 本节检查

- 研究对象和问题清楚，缺口对应可回查的文献或比较证据。
- 每项贡献可定位到方法和结果，未承诺正文未验证的能力。
- 引用的对象、条件和强度与来源一致，最强相关路线没有被回避。
- 最终版承诺与正文一致；局部修改只报告实际检查过的范围。
