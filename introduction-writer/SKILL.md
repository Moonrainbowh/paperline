# 引言写作（introduction-writer）

开始前读取已有 `paper_context`，并使用 `literature-research` 的检索和阅读结果。写作顺序通常是：研究背景 → 当前进展 → 尚未解决的问题 → gap → 本文目标与方法 → 有证据支撑的贡献。

起草或实质重写时读取 [引言规则](references/introduction-rules.md) 和 [分节写作协议](../paper-navigator/references/shared/section-writing.md)，明确本节主张、证据、段落任务与交付位置。语言和局部修改遵循 [共同原则](../paper-navigator/references/shared/writing-principles.md) 与 [局部修改规则](../paper-navigator/references/shared/local-editing.md)，默认中文，不自行转成英文投稿稿。

若提供了与当前目标期刊、研究方向和 Article Type 匹配的 `target-journal-guide.md`，使用其中的读者定位、引言组织和篇幅建议；它不替代 `literature-research` 的科学证据。

引言中的每个重要判断都要能对应文献或用户提供的研究材料。文献只承担其实际支持的范围，不用标题相关性替代证据。

如果主旨、gap 或贡献仍有实质歧义，先给出段落蓝图并标记少量“待确认”问题；局部修改时只改用户指定范围及必要的一致性位置。

完整论文流程区分引言第 0 版和最终版：第 0 版是方向脚手架；方法、结果、讨论及相关文献综合稳定后，回写最终引言，再交给摘要写作。独立引言任务只完成本轮请求，不要求用户先完成整条流水线。本 Skill 报告章节检查和未决问题，正式阶段确认由 `paperline` 汇总。
