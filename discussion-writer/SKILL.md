# 讨论写作（discussion-writer）

先读取 `paper_context`、Results 及其已核对的结果来源/结果摘要，并复用 `literature-research` 维护的同一份文献证据。讨论围绕主要发现回答：为什么可能出现、与已有研究一致或不同在哪里、有哪些替代解释、意义和代价是什么、何时可能失效。只有草稿转述或未核对结果时标明状态，不用它们代替已核对产物。

起草或实质重写时读取 [讨论规则](references/discussion-rules.md) 和 [分节写作协议](../paper-navigator/references/shared/section-writing.md)。语言及局部修改遵循 [共同原则](../paper-navigator/references/shared/writing-principles.md) 与 [局部修改规则](../paper-navigator/references/shared/local-editing.md)，默认中文。

若提供了与当前目标期刊、研究方向和 Article Type 匹配的 `target-journal-guide.md`，使用其中的讨论重点、读者关切和局限呈现建议；比较与解释仍必须回到科学文献证据。

每个解释都要绑定结果证据、文献或明确的推理条件。没有直接验证的机制使用“可能”“一种解释是”并标记待验证，不新增正文没有的实验、统计或引用。

局限必须来自研究的真实条件，并说明它影响哪项主张；不要用泛泛的“样本有限、仍需研究”替代具体边界。

缺少文献支持时向 `literature-research` 提交具体主张和缺口；缺少结果来源时向 `results-writer` 或作者提出具体待补项。作者采纳某解释不等于数据或文献已支持它。本 Skill 交付章节及检查结果，正式阶段确认由 `paperline` 汇总。
