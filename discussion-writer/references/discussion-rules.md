# 讨论规则

讨论段落可以按以下链条组织：核心发现 → 结果证据 → 可能原因/机制 → 与已有研究比较 → 替代解释 → 成立条件 → 边界。

区分结果一致、方向一致但量级不同、条件不同时不可直接比较和真正冲突。工程或理论意义必须说明使用条件、代价和失败风险。结论强度不能超过研究设计和证据。

## 讨论蓝图

按核心回答 → 主要发现解释 → 与已有研究对话 → 替代解释与异常 → 意义及代价 → 具体局限组织相关内容，不强迫每张图对应一段讨论。

为每个主要解释段先列：解释哪项发现、结果来源、候选机制、可比较的文献条目、未排除因素和成立边界。然后扩写为连贯段落，推断强度由实际设计和证据决定；核心因果或机制存在科学选择时提交作者，不自动强化结论。

比较文献先声明对象、条件、尺度或指标等比较轴。相关正文未读或无法定位时标记待补，不能因题名相似就写“一致”或“矛盾”。差异原因没有直接证据时只能作为候选解释。

局限写清真实限制、来源、可能影响的主张以及哪些结论仍成立；未来工作只对应具体未决问题。新增分析需先报告在 Results 并交代方法，不能仅在 Discussion 出现。

## 本节检查

- 主要解释贴合真实发现、证据来源与适用条件，没有逐图重复。
- 影响中心结论的替代解释和冲突证据得到处理或明确保留。
- 无新结果，因果、机制、外推强度不高于研究设计及证据。
- 意义、代价与局限具体，作者决定和证据核对状态分开。
