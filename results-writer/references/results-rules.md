# 结果规则

结果段落建议包含：研究问题或有限主张、数据与比较条件、主要观察、定量结果、不确定性/异常、能够支持的局部结论和边界。

Results 可以报告紧邻证据的观察与有限判断，但不要在这里展开长机制解释、因果推断或普遍适用性。用户没有提供的数字、显著性、泛化范围和失败条件必须标记为缺失或待确认。

## 发现顺序与段落蓝图

先确定本小节要回答的问题及最重要观察，再选择结果记录和图表。可按可信度/校核 → 主要发现 → 公平比较 → 敏感性或补充验证 → 异常与失败组织；只采用实际存在且相关的结果。

每段通常按有限主张 → 数据/工况与比较条件 → 主要观察和定量结果 → 不确定性或异常 → 图表指向及局部边界组织。图表编号是证据位置，不承担段落主旨。合并 Results 与 Discussion 时，仍明确哪些句子是观察、哪些是解释。

## 本节检查

- 核心数值、方向、单位、条件和比较对象与原始来源一致。
- 关键结果在 Methods 中有相应定义；新增指标或分析不静默进入正文。
- 异常、失败和不确定性没有被措辞隐藏，统计显著性不等于工程价值。
- 每项核心发现能回查证据；需要机制解释的内容交给 Discussion。
