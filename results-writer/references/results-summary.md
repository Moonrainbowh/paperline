# 结果摘要与接力

用于先整理结果再起草、为 Discussion 准备上游材料，或更新已有结果摘要。它记录用户研究的实际结果，不替代原始数据、图表、统计输出或方法。

多轮任务沿用现有结果文件；尚无文件时可写 `results-summary.md`。小范围请求可直接在对话交付。按一个可核查结果一条记录整理：

| 字段 | 内容 |
| --- | --- |
| 结果及问题 | 结果编号、本项回答的问题、观察方向；沿用既有编号 |
| 来源位置 | 原始文件路径及版本、表格行列、图/子图、日志或统计输出位置 |
| 来源状态 | 用户提供、草稿转述或已对照产物核对；写清实际核对范围 |
| 条件 | 对象、工况、样本量、数据划分、控制条件和评价范围 |
| 数值与单位 | 原始指标、数值、单位、方向；派生值说明公式及输入来源 |
| 比较对象 | 基线/对照及其数值、指标定义和比较条件是否一致 |
| 不确定性 | 重复、误差、区间、统计/显著性或敏感性；未提供写“未提供” |
| 支持与边界 | 能支持的有限主张、异常/失败、不能推出的机制或泛化 |
| 缺项 | 缺单位、条件、原始输出、图注或统计定义及需补材料 |

同一结果在正文、表格和日志中不一致时并列记录冲突，不自行选一个数值。直接观察、计算所得和解释性推断分开；没有统计判据不能补写“显著”。对源文件无法读取或未对照的记录不能写“已核验”。

起草前按 [结果规则](results-rules.md) 从摘要选出发现顺序和每段证据。交给 Discussion 时指出可用结果及其来源状态、条件、比较和边界；缺失信息仍保持缺失，作者采纳也不等于已经核对产物。
