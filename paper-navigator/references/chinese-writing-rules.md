# 中文学术写作的段落与句子规则

用于中文论文的起草、重写和逻辑检查。约束句子的功能，不强迫所有论文使用相同句式或固定句数。

## 四层写作单位

| 层级 | 核心问题 | 必须产物 |
| --- | --- | --- |
| 论文级 | 整篇论文要证明或说明什么 | 主旨、贡献、证据、边界 |
| 章节级 | 本章必须回答什么，不能承担什么 | 章节契约 |
| 段落级 | 本段唯一任务是什么 | 主题句、证据/解释锚点、前后关系 |
| 句子级 | 本句在论证链中做什么 | 可识别的功能标签和中心命题 |

## 句子功能标签

写作规划时可以标注，交付的论文正文必须删除标签。

| 标签 | 功能 | 必须回答 |
| --- | --- | --- |
| `【定】` | 定义或定位 | 对象、概念、场景或范围是什么 |
| `【问】` | 问题或缺口 | 什么在什么条件下尚未解决，后果是什么 |
| `【主】` | 主张或主题句 | 本段希望读者接受什么判断 |
| `【法】` | 方法或研究动作 | 做了什么，作用于什么对象 |
| `【据】` | 数据或来源证据 | 在什么条件下观察到什么 |
| `【比】` | 比较 | 与谁按什么统一标准比较 |
| `【释】` | 解释 | 结果意味着什么，可能由什么机制产生 |
| `【界】` | 边界 | 结论适用于哪里，哪里尚未验证 |
| `【转】` | 过渡 | 上一命题如何引出下一命题 |

无法标注功能的句子通常是空话、重复或错位信息，应删除、合并或移动。

## 通用段落合同

段落不必机械地包含所有句位，但必须形成可追踪的逻辑：

```text
主题或任务
→ 必要的证据/事实/方法细节
→ 解释或比较
→ 边界、局部结论或下一段问题
```

写段落前记录：

```text
段落ID：
唯一任务：
主题句：
证据或解释锚点：
与上一段关系：
支持的章节主张：
不能在本段声称：
```

## 常用功能链

| 段落类型 | 推荐功能链 |
| --- | --- |
| 背景段 | `【定】对象 → 【据】重要性/现状 → 【问】具体困难 → 【转】收束` |
| 文献综合段 | `【定】方法族 → 【法】共同机制 → 【据】已有进展 → 【界】能力边界 → 【转】本文问题` |
| 方法模块段 | `【问】模块要解决的问题 → 【法】输入与操作 → 【定】参数/设定 → 【释】设计理由 → 【法】输出与衔接` |
| 结果段 | `【问】验证问题 → 【定】条件 → 【据】观察与数值 → 【比】比较/统计 → 【界】局部结论` |
| 讨论段 | `【主】解释性判断 → 【据】结果锚点 → 【释】机制 → 【比】已有研究/替代解释 → 【界】成立条件` |
| 局限段 | `【界】具体限制 → 【释】来源 → 【据】可能影响 → 【界】受影响与仍成立的结论 → 【转】可验证后续工作` |

## 中文句子的硬规则

1. 一句话只保留一个中心判断；一句可以有从句，但不能同时承担多个互不从属的结论。
2. 明确主语，避免在“已有研究、本文方法、数据和实验结果”之间隐式切换。
3. 定义先于使用；术语、缩写、符号和贡献名称一旦锁定就全文一致。
4. 数字必须绑定研究对象、条件、指标、单位和比较对象。裸百分比不能作为完整证据。
5. 比较必须使用可比条件；数据、划分、预算、指标或工况不同就说明差异。
6. “显著”只用于有统计检验或明确工程阈值的语境，并说明判据。
7. “证明、导致、决定、建立因果”必须与数学证明或研究设计的证据强度匹配。
8. 相关或预测证据通常使用“表明、提示、与……一致、在当前条件下支持”等有边界表达。
9. “其、该、这、上述”必须有唯一明确的先行对象；有歧义时重复具体名词。
10. 长串定语、连续逗号和多层括号降低可读性时，拆成两句并显式写出逻辑关系。
11. 引用紧邻被支持的原子主张，不用段末一串引用覆盖多个不同命题。
12. 最终句不强制承担过渡；只有确有因果、转折、递进或范围关系时才写过渡。

## 证据强度与动词

| 证据状态 | 推荐表达 | 避免表达 |
| --- | --- | --- |
| 直接且充分 | 表明、显示、支持；严格证明时可用“证明” | 无边界的“普遍证明” |
| 局部或单一数据范围 | 在本数据/工况下表明、支持 | 普遍适用、全面验证 |
| 间接或趋势证据 | 提示、与……一致、可能反映 | 证实机制、导致 |
| 相关性证据 | 与……相关、伴随……变化 | 导致、决定 |
| 尚未验证的机制 | 可能与……有关、有待进一步检验 | 机制已经明确 |
| 无证据 | 标记待验证或删除 | 用引用、修辞或自信语气掩盖 |

## 常见空转表达

下列表达只有提供具体内容后才保留：

- “随着……快速发展”——改为直接说明研究对象和具体变化。
- “众所周知、显而易见、值得注意的是”——删除或换成证据。
- “仍存在一定不足”——指出对象、条件、限制和后果。
- “取得了良好/显著效果”——给出指标、基线、数值和范围。
- “充分证明了方法的优越性”——改为证据能够支持的限定结论。
- “填补了空白、首次实现”——需要可复现检索范围和直接比较。
- “具有重要意义和广阔前景”——说明具体新增能力、使用情境、代价和边界。

## 面向后续英文转换的中文准备

- 保持主语明确，不依赖中文省略主语。
- 一项术语只使用一个锁定名称，不为“避免重复”随意换同义词。
- 把因果、转折、比较、限制和递进关系写清楚，但不堆砌连接词。
- 区分数据观察、作者解释、文献观点和未来假设。
- 保留原始数值、单位、符号、引用和图表编号，不在语言润色时改动事实。

## 起草输出

正式写作前有实质歧义时，先交付段落蓝图；确认后再写正文：

```text
章节任务：
段落蓝图：
句子功能链：
证据锚点：
适用边界：
待作者确认：
```

正文交付时，将规划标签全部移除，并另列仍缺的证据、引用或作者决策。
