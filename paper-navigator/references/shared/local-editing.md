# 局部修改规则

当用户要求修改某一节、某一段、一个术语或一个图注时：

1. 确认用户要求的范围和目标产物；
2. 只检查与该范围直接相关的前后文、数字、术语和交叉引用；
3. 完成局部修改；
4. 做必要的一致性检查；
5. 报告仍需作者决定的问题。

研究问题、结果、来源或期刊要求改变时，沿已有 `paper-map.md` 或相关段落列出影响位置：章节/句段、图表、引用、结果摘要及摘要/结论。先修复最早发生变化的材料，再把当前采用的版本交给受影响的 writer；缺来源交 `literature-research`，跨章节或逐句审查交 `manuscript-reviewer`。

交付时留下“本轮更新位置、当前输入与输出、已做检查、下一项任务”，让后续工作能从具体文件或段落继续。没有文件时使用对话中可明确定位的内容，不为了恢复添加新的状态文件。

涉及正式 `paperline` 的稿件锁或下游产物时，把变化及影响清单交回编排层，按其既有失效/重新确认规则恢复；局部修复不授权复用旧锁。确认记录已经覆盖的普通措辞修改不另加确认门，科学含义或已确认范围的变更才保留给作者决定。

不要因为局部修改而重写全文，也不要顺手改变用户没有要求的研究主张、数据、贡献排序或章节结构。
