# 分节写作与交接

供章节 writer 按需读取。单段润色且主张、证据、边界清楚时直接改写，参考 [局部修改规则](local-editing.md)；不强制生成地图或另存文件。正式论文的阶段和作者锁由 `paperline` 管理。

## 先明确本节，再起草

1. 识别本节唯一任务、当前采用的正文、可用文献/图表及输出位置。沿用已有材料和已确认决定，缺项区分“阻塞本轮”与“后续待补”。
2. 对新章节或大幅重写，先列原子主张、证据位置、适用边界与段落顺序。可用短表或主题句序列，不强制固定模板。
3. 完整项目把本节蓝图交给 `paperline` 汇入 `paper-map.md`；局部任务在当前回复中留蓝图即可。已有蓝图适用时复用。
4. 按问题和证据扩写正文；默认中文。只使用实际材料中的数值、方向、显著性、研究设计和来源，不把解释写成观察结果。
5. 检查每段主题、发现/解释与来源的对应关系，以及数字、单位、术语和图表引用；必要时做局部反向提纲。逻辑和证据稳定后再压缩铺垫、重复和语言。
6. 交付正文或指定文件，附必要缺项、实际检查结果与下一步输入。候选修订与作者已采用稿件区分清楚。

仅当缺失或歧义会改变科学含义、主旨、贡献取舍或既有确认边界时，停在相关问题上等待作者决定。现有授权足以完成的规划和写作不额外增加“蓝图批准”步骤。

## 主张与证据

- 研究结果绑定实际图表、统计输出或数据位置；文献主张绑定共享证据表及原文位置。DOI、题名或作者年份核验不能证明语义支持。
- 保留 `literature-research` 已记录的阅读状态、支持等级和适用边界，不在章节写作中另建评分。
- 作者确认记录与证据核验记录分别保留。已确认但缺证据的表述仍需标出来源缺口；不要擅自覆盖作者采用的版本。
- 证据缺口交给 `literature-research`，跨章节逻辑或逐句审计交给 `manuscript-reviewer`，实际修订交回对应 writer。

专业章节细则由各 writer 的本地 references 定义。需要详细中文主张地图或反向提纲时，按需读取 [主张与证据约束](../writing-claim-evidence.md) 和 [反向提纲](../reverse-outline-consistency.md)，不把旧 Router 的整套正式流程加载到每次局部写作。
