# 讨论、局限性与结论的中文写作规则

讨论回答“怎样理解结果、与谁不同、何时可能失效”，结论回答“本文最终解决了什么、凭什么、意义和边界是什么”。

## 讨论

### 章节任务

从具体发现向科学或工程意义展开，同时检验替代解释、已有研究关系、代价和局限。不要逐图复述结果，也不要新增正文未报告的分析。

### 默认段落蓝图

| 段落 | 唯一任务 | 推荐句子功能序列 |
| --- | --- | --- |
| D1 核心回答 | 直接回答研究问题 | 回扣问题 → 核心发现 → 决定性证据 → 有边界的总体解释 |
| D2—Dn 主要发现解释 | 每段解释一项主要发现 | 解释性主张 → 结果/图表锚点 → 可能原因或机制 → 成立条件 → 可信度边界 |
| 已有研究对话 | 说明一致、差异和新增认识 | 比较维度 → 一致/差异 → 差异可能来源 → 本文新增认识 |
| 替代解释与异常 | 防止把相关写成因果 | 合理替代解释 → 支持/反驳证据 → 未消除不确定性 → 是否动摇核心结论 |
| 工程/理论意义与代价 | 落到使用情境或概念变化 | 应用情境 → 新增能力 → 成本/复杂度/性能权衡 → 适用条件 |
| 局限性 | 说明结论在哪里停止 | 具体限制 → 来源 → 可能影响方向 → 受影响和仍成立结论 → 可验证后续工作 |
| 收束（可选） | 从发现回到整体意义 | 综合解释 → 有边界的意义或开放问题；另有结论时保持简短 |

多个主要发现可以重复“解释段”，但不能按每张图机械生成一个讨论段。

### 讨论段合同

```text
本段解释的发现：
解释性主张：
结果证据锚点：
可能机制：
已有研究比较：
替代解释：
成立条件：
不确定性或边界：
```

“可能源于……”后必须跟随推理、文献或实验支持；只有想象而没有证据时，标记为待验证假设。

### 与已有研究比较

- 先声明比较轴，例如研究对象、工况、数据、机制、指标或尺度。
- 区分“结果一致”“方向一致但量级不同”“条件不相同不能直接比较”“结论冲突”。
- 差异原因没有直接证据时写成候选解释，不写成既定机制。
- 说明本文增加了哪项认识，不只说“与前人一致”。

### 替代解释

至少对影响核心贡献的主要解释进行检查：

1. 还有哪些因素能产生相同观察？
2. 当前设计排除了哪些因素？
3. 哪些因素尚未排除？
4. 未排除因素会削弱哪一项主张，是否影响中心结论？

替代解释不是为了自我否定，而是为了校准因果、机制和推广强度。

### 局限性

局限必须来自研究内部的真实条件，而不是通用免责声明。写清：

- 受限对象或条件；
- 限制来源；
- 对数值、方向、机制或外推的可能影响；
- 哪些结论受影响，哪些仍然成立；
- 后续应通过什么具体数据、实验或分析验证。

不要用“样本有限、仍需更多研究”作为完整局限段。

### 常见失败

- 逐图重复结果，没有解释和综合。
- 加入新的数据、统计、指标或图件。
- 把相关性、预测性能或单一案例写成因果机制。
- 只选择支持本文的文献，不处理冲突证据。
- 把局限隐藏到无关紧要的末句。
- 未来工作是愿望清单，没有对应当前不确定性。
- 工程意义不写部署条件、成本或失败风险。

## 结论

### 章节任务

用紧凑文字闭合研究问题、核心贡献、决定性证据、意义和边界。结论不是摘要复制，也不是结果列表。

### 默认结构

| 段落 | 唯一任务 | 推荐句子功能序列 |
| --- | --- | --- |
| C1 研究回答 | 说明解决了什么和怎样解决 | 准确重述问题 → 核心方法/研究动作 → 核心贡献 |
| C2 决定性证据 | 说明凭什么得出结论 | 最关键结果 → 必要定量/比较证据 → 支持哪项贡献 |
| C3 意义与边界 | 说明价值和停止位置 | 理论/工程意义 → 适用范围 → 最重要局限 → 可选具体后续方向 |

期刊要求单段结论时可以合并C1—C3，但不能删除证据和边界。

### 结论禁止项

- 新数据、新图表或新统计结果。
- 讨论中没有论证的新机制。
- 前文没有出现的新引用或新贡献。
- 无证据支持的“首次、普适、彻底解决、显著有效”。
- 逐项复述每张图和每个结果。
- 只写“未来值得进一步研究”而不指出具体未决问题。

### 结论回溯检查

| 结论内容 | 必须回溯到 |
| --- | --- |
| 研究问题 | 引言的精确缺口和研究目标 |
| 核心方法 | 方法章节的关键动作 |
| 决定性结果 | 结果章节的图表/数据证据 |
| 解释和意义 | 讨论章节的综合论证 |
| 局限和边界 | 讨论的局限性及研究设计范围 |

## 章节质量门

### 讨论通过条件

- 主要发现都有解释、已有研究关系和适用边界。
- 影响中心结论的替代解释已经提出并评估。
- 没有新增结果，推断强度不高于研究设计和证据。
- 局限具体说明影响方向和受影响主张。
- 工程或理论意义包含条件、代价或不确定性。

### 结论通过条件

- 中心贡献与一句话主旨一致。
- 决定性证据准确且与正文数字一致。
- 没有新数据、新机制、新引用或新主张。
- 意义不宽于讨论，边界不宽于方法和结果。
- 最终结论可以与摘要末句和标题形成一致闭环。
