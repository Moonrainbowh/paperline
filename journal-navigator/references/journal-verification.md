# Journal Verification：官方条件、时效性与未知

用于模式 A 的 Step 5–6，也用于目标期刊指南的提交前复核。

## 1. 核验项目

逐刊检查以下会改变可投性的条件，并给出 `满足 / 不满足 / unknown`：

1. Aims & Scope 是否覆盖研究问题和贡献类型；
2. 是否接受当前 Article Type 和栏目；
3. 用户指定的 SCI、EI、Scopus 等收录是否由指定索引官方记录确认；
4. OA/APC、语言、长度、图表、数据/代码和伦理政策是否可满足；
5. 投稿系统、期刊身份、专题截止和接收状态是否正常；
6. 是否有停刊、撤刊、异常警示或身份混淆风险。

`unknown` 不等于 `pass`，但不需要为普通报告维护候选 ID、状态机或 frontmatter。写明缺什么证据、影响哪个结论、应到哪里补核验。

## 2. 来源优先级

| 来源 | 可支持内容 |
| --- | --- |
| 期刊/出版社官方页面 | Scope、Article Type、费用、作者指南、投稿政策 |
| 指定索引数据库官方记录 | 收录状态 |
| 正式出版论文或可确认全文 | 近年主题、方法、证据和写作观察 |
| 聚合网站、搜索摘要、经验帖 | 发现线索，不单独支撑正式判断 |

不要让一个首页链接替所有字段背书。引用能直接支持该项结论的页面、DOI 或正式论文。

每条会影响判断的记录至少写明“字段、当前结论、直接来源、核验日期、未知项及影响”。例如 Article Type 与字数分别链接相应作者指南条款，APC/OA 链接费用政策，索引链接指定数据库的官方记录。候选对比表可合并展示这些记录，但不能用统一官网首页或统一查询日期掩盖某个字段尚未核验；共享论文证据支持范围匹配与发文连续性，不能替官方页面证明费用或投稿条件。

## 3. 时效性

范围、费用、OA、索引、作者指南、数据/伦理政策、投稿状态和专题截止必须注明核验日期，并在提交前按当前页面复核。没有统一的“30 天过期”规则；按字段变化速度和投稿时点判断。

没有官方接受率或审稿周期统计时，不写确定数字或承诺。影响因子、分区、引用量也不能代替主题匹配。

## 4. 证据等级与结论边界

- 官方规则说明期刊允许什么，不能单独证明近年持续发表什么；
- 一篇相似论文说明存在先例，不能证明稳定兴趣；
- 多篇跨年份强邻近论文形成文章簇，才支持持续关注判断；
- 只有摘要时，只判断摘要可支持的主题和公开贡献，不推断全文方法、验证、讨论或结构；
- 样本观察不能升级成官方规则；
- 不预测录用概率，不复制论文原句，不把改写问题和证据缺口混为一谈。

## 5. 正式 Paperline P2 交接

独立报告默认不需要正式合同。由 `paperline` 调用正式 P2，或用户已明确授权接入该流程时，沿用 `target-journal-decision.md` 和 `target-journal-writing-contract.md` 的既有格式，并分别运行 `scripts/validate_journal_artifacts.py`；不再额外询问是否要启动同一交接。

会改变可投性或作者取舍的未知硬条件尚未解决时，决定/合同保持 `draft` 或 `pending_confirmation`，写清缺项及补核验位置。只有作者已确认当前选择与确切合同、相关硬条件已核实且两份正式产物通过既有校验，才交回 `paperline` 完成锁刊；短名单和 `target-journal-guide.md` 都不能替代。校验器验证结构和绑定，官方真实性与字段时效性仍由本 Skill 按上述来源规则核验。
