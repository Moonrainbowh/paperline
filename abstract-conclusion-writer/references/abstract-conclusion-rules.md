# 摘要与结论规则

摘要至少覆盖：背景/问题、目标、方法、关键结果、意义和边界。结论至少覆盖：回答了什么问题、采取了什么方法、哪项证据支撑核心贡献、意义在哪里以及结论停止在哪里。

禁止新增数据、图表、统计、机制、引用、贡献和无证据的“首次/普适/彻底解决”等强断言。所有数字、术语和贡献数量都应能回溯到正文。

## 功能蓝图与回溯

摘要按对象与问题 → 必要缺口 → 目标/方法 → 验证范围 → 决定性结果 → 意义和边界压缩。决定性结果保留条件、指标和必要比较；篇幅紧时减少次要结果，不把限制改成无限外推。期刊要求结构化摘要时按真实栏目组织，未给规则不猜测栏目和字数。

结论按研究回答 → 核心动作及贡献 → 决定性证据 → 意义和边界组织，不复制摘要或逐图列结果。要求单段时可以合并功能，不能因此删掉证据或边界。

| 内容 | 必须回溯到 |
| --- | --- |
| 问题与缺口 | 最终引言及已核验文献 |
| 方法与范围 | 方法章节 |
| 关键数值与比较 | 结果章节及对应图表/数据 |
| 解释和意义 | 讨论章节 |
| 局限与外推边界 | 研究设计与讨论中的限制 |

标题和关键词可以早拟，最终锁定时覆盖正文实际对象、方法/发现和范围，不加入未经论证的性能、因果或热点词。默认不向摘要追加引文；期刊明确要求或允许时按其规则处理。

## 本节检查

- 每个实质句都能回查正文，数字、术语、贡献数量一致。
- 无新结果、机制、引用或贡献，意义不宽于讨论，范围不宽于研究设计。
- 标题、摘要末句与结论形成同一有边界的回答；未解决冲突明确列出。
