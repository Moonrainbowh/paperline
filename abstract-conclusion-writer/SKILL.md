# 摘要与结论写作（abstract-conclusion-writer）

先读取 `paper_context`、Introduction、Methods、Results 和 Discussion。摘要压缩研究问题、方法、关键结果、意义和边界；结论闭合研究问题、核心贡献、决定性证据和适用范围。

起草或实质重写时读取 [摘要与结论规则](references/abstract-conclusion-rules.md) 和 [分节写作协议](../paper-navigator/references/shared/section-writing.md)。语言及局部修改遵循 [共同原则](../paper-navigator/references/shared/writing-principles.md) 与 [局部修改规则](../paper-navigator/references/shared/local-editing.md)，默认中文。

若提供了与当前目标期刊、研究方向和 Article Type 匹配的 `target-journal-guide.md`，使用其中的摘要结构、篇幅和结论侧重点建议；不得因此增加正文没有的新主张。

标题和关键词应反映正文真正覆盖的对象、方法和问题。摘要或结论中不能出现正文没有的新数字、新实验、新机制、新引用或新贡献。

如果正文数字、贡献数量或术语互相冲突，先报告冲突并给出待确认版本，不替作者选择。

完整流程中，结论在结果与讨论后闭合；摘要、标题和关键词在最终引言与正文稳定后定稿。阶段或最终版本锁定由 `paperline` 协调作者完成，本 Skill 只交付相应文本、正文映射和检查结果。局部摘要/结论请求不扩为全稿重写。
